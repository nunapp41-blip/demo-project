Backend API — inspect directly

All paths below are served by the same Node.js backend. Public status endpoints are safe to open. Private endpoints correctly require an authenticated account.

/healthz · /readyz · /v1/system/status · /v1/config · /v1/me

Real public video metadata endpoint: GET /v1/public/video/VIDEO_ID/metadata. See Live YouTube Tools to try it.

Authenticated APIs: /v1/dashboard, /v1/rank/track, /v1/competitors, /v1/retention/:videoId. These are only accessible with proper access credentials.

Operations, logs and infrastructure are managed separately in Render. The full source, workers, extension and tests are in GitHub.
