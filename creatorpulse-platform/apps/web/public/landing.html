FREQUENT QUESTIONS

Know exactly what you're getting.

Are these real YouTube analytics?

Real public stats require a configured YouTube Data API key. This public preview uses labeled sample data.

Can I track my own audience retention?

Only with an owner-authorized YouTube Analytics OAuth connection, a supported video and approved scopes.

Can the whole project run without paid tools?

Yes, core code is self-hostable with open-source software. Public hosting, domains, API quotas, and payment processing can incur independent costs.
